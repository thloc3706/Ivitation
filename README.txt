THIỆP MỜI "KHÚC MỘC VÂN"
========================
1. Giải nén, giữ nguyên cấu trúc thư mục (index.html, style.css, script.js, thư mục assets/).
2. Mở bằng VS Code -> chuột phải index.html -> "Open with Live Server" (hoặc: python -m http.server 8000).
3. Sửa nội dung: đầu file script.js (invitationData, LOGO_SRC).
   Màu: :root trong style.css. Thời gian hiệu ứng: CONFIG trong script.js.
